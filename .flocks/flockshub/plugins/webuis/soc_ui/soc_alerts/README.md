# 告警调查查询约定

- 首次进入默认查询最近 7 天、全部来源和全部协议。来源按实际值展示，深信服为“深信服 SIP”，缺失协议统一为“未知协议”。
- 下拉菜单支持多选、全选、清空、取消和确定；确定只保存选择，点击页面“查询”或在关键词框回车才执行。尚未提交时显示提示。
- “清空筛选”立即清除所有业务筛选和关键词并重新查询，保留当前时间范围。
- 候选项来自后端 `filterOptions`，按当前时间范围和用户权限统计，忽略业务筛选且不受列表返回条数限制。已选但不在候选中的值仍可取消。
- 空状态区分查询中、请求失败、当前时间范围没有告警，以及有告警但筛选无匹配；后者可一键清空。无告警时建议扩大时间范围或检查研判入库，不据此断言设备未接入。
- 应用与 SOC 页面插件一起更新可启用完整候选聚合。页面兼容旧响应，缺失候选字段时回退到列表中的可见值；旧应用不具备完整候选聚合能力。

后端绑定使用 `facetFields` 显式声明候选字段，只允许声明当前 contract 可筛选且驱动可提供的字段。统计遵循时间、权限及去重规则，不为无权查看的来源返回候选。
